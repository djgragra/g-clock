# Changelog

## 26.10.3 — 2026-10-13

- **Fixed events**: events at a time of day (news at 18:00, ad block at 18:20, a guest on air), each on the days you choose. Under the dial the clock shows the next one with a countdown, warns you once (the bar turns red at the number of seconds you set for that event, 60 by default) and says NOW for ten seconds when it is time. Settings → Events. Times are wall-clock times in the clock's time zone.
- **Stopset schedules by day and hour**: other sets of stopset minutes for certain days and hours (for example `0, 20, 40` on weekday afternoons, `15, 45` at the weekend). The first schedule that fits the time of the clock applies, the minutes you already had apply outside them, and the dial redraws itself when a schedule starts or ends. A schedule can run past midnight. Without schedules nothing changes.
- **New logo and look**: the studio dial as a logo (60 minute segments, the current minute lit, a blue stopset marker, the red On Air dot), drawn as SVG; the app icons for Windows, macOS and Linux are generated from it. The interface now has the family look of the other OnAir Garage apps: a header with the logo and a status pill (how many feeds answered), headlines and weather as cards, rounded controls, soft shadows, small transitions that are switched off when the system asks for less motion, and a welcome with the logo when there is no feed yet. Nothing changes in what the clock does.
- **Guided update, the same in every OnAir Garage app**: a thin strip under the header offers **Download and install**, **Remind me later** (24 hours), **Skip this version** and the release notes; a progress bar with a Cancel button; the installer is checked against the published SHA-256 sums. **Close and install** makes a **safety copy** of the settings first (the last 3 are kept), then on Windows closes the app and starts the installer, on macOS opens the disk image, on Linux shows the AppImage; it asks first if the recording timer is running. After the update a **What's new** window shows once. Settings → Updates shows the same states, the last check and **Check now**. The strip never covers the dial: it stays out of the way in full screen and while recording. Nothing is installed without a click.
- **No more `.part` leftovers**: an installer download that is cancelled, stalls, fails or does not match its checksum now always deletes its temporary `.part` file (the file is closed before it is deleted, which Windows requires), and a `.part` left by an earlier run, for example when the app was closed in the middle of a download, is removed at the next start and before the next download.
- **Backup like the other apps** (Settings → Backup): export or import the whole configuration as `g-clock-backup-YYYY-MM-DD.json`; on import you choose **Replace everything** or **Add only the missing items**. The file holds no passwords or keys (G-Clock uses none). Older settings files still import.
- **Signature of the OnAir Garage apps**: a **Help & About** tab with credits, links, **Copy support info** (version, system, language, last update check and last error; never settings, addresses or file names) and **Open logs folder**; Settings tabs in the standard order; daily log files of at most 5 MB, 7 days kept.
- `CLAUDE.md` is now part of the repository and points to the standard the app is built under.
- Tests: 92 (new ones for schedules and events, the backup, the guided update with a fake GitHub including the `.part` cases, the safety copy, the changelog in the package, the logs, the support info, the icon files and the same keys in English/Italian/Spanish).
